# XR FUSION EDU — versión corregida

## Modelos integrados
La biblioteca incluye los 5 archivos GLB de `models/`. La portada original se conserva.

## Cómo ejecutar
1. Extrae el ZIP completo.
2. Abre la carpeta extraída en Visual Studio Code.
3. Ejecuta `index.html` con la extensión Live Server.
4. Pulsa **ENTRAR AL LABORATORIO**. Los 13 modelos aparecen en **BIBLIOTECA 3D** a la izquierda.

No muevas `index.html` fuera de la carpeta ni separes `models/`: las rutas de los modelos son relativas (`./models/nombre.glb`).
